# El Yunque · Ludaria

Sesión 9, secundaria 1 del módulo 3. Taller de 90 min sincrónicos y 90 autónomos. Diez pantallas para narrativa, misiones, progresión, componentes y bitácora del prototipo. Ver GUIA_DOCENTE.md.

Abrir presentacion.html o index.html. Configurar canvasExterno y bitacoraExterna en config.js únicamente con URLs reales HTTPS. Ejecutar preparar_publicacion.py después de editar CSS, contenido, configuración o app y publicar entradas y recursos generados. Alternativas locales completas mientras faltan enlaces.

Publicación e iframe se registrarán tras verificar el navegador. El HTML conserva respuestas en el dispositivo, no las envía al docente ni acredita atributos. No modifica el portal ni otras misiones.
