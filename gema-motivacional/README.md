# La Gema Motivacional

Sesión 7 · secundaria 2 y cierre del módulo 2 · Cantera de los Elementos · Maestra Bryn · Maestría.

Doce pantallas para una clase sincrónica de 90 minutos: tres facetas, dos dilemas, tres prácticas con pistas, fichas de rediseño, intercambio entre equipos y cierre con el Fragmento II. Tesis, tabla 8, pp.42–43; Ryan y Deci (2020); Kim y Werbach (2016). Fuentes y límites integrados.

## Incrustar

```html
<iframe src="https://nespinozagonzalez-hub.github.io/misiones/gema-motivacional/presentacion.html" title="La Gema Motivacional · Misión secundaria 2 del módulo 2" width="100%" height="720" style="border:0;" allow="fullscreen" allowfullscreen></iframe>
```

El facilitador anuncia cada pantalla. La navegación permanece libre. Los candados abren solo pautas complementarias; los sellos distinguen práctica resuelta y apertura acompañada. Las respuestas abiertas requieren revisión humana.

## Archivos

- `content.js`: textos, campos, prácticas y referencias.
- `app.js`: navegación, cuaderno, modales, temporizador y registro local.
- `config.js`: URL opcional del formulario de cierre, vacía al entregar.
- `styles.css` y `assets/gema.webp`: estilo aprobado e ilustración original.
- `GUIA_DOCENTE.md`, `PROMPT.md` y `GUION.json`: conducción, alcance y diseño.
- `prueba.html`: marcos de escritorio y móvil.

Después de editar, ejecutar `python3 preparar_publicacion.py`. Genera recursos con hash y actualiza ambos HTML de entrada. Conservar assets antiguos mientras haya HTML en caché. La versión portátil incorpora sus recursos y no requiere servicios externos para funcionar.

## Límites de funcionamiento

Clave local exclusiva `ludaria_gema_motivacional_v1`. Cuaderno y copia/TXT permiten conservar respuestas; no se envían desde el HTML ni se sincronizan entre dispositivos. La configuración del formulario de cierre permanece pendiente: usar el canal indicado en clase. El receptor diagnóstico de Misión 0 no se utiliza. El cierre del Fragmento II es narrativo y local; los códigos reales se gestionan en las herramientas existentes.

El temporizador no cambia de pantalla. Texto, teclado, modales y movimiento reducido están contemplados. En pantallas móviles se permite desplazamiento vertical legible. La guía detalla las fuentes y la distinción entre teoría, interpretación y casos ficticios.
