# Los Planos del Arquitecto · Ludaria

Sesión 8, misión principal del módulo 3. Catorce pantallas para clase de 90 min y continuidad autónoma de 60 min. Canvas educativo 6D propio, caso completamente resuelto, miniactividades y revisión rápida entre pares. Ver GUIA_DOCENTE.md para conducción y fuentes.

Abrir presentacion.html o index.html. Configurar canvasExterno en config.js solo cuando exista una URL real HTTPS. Ejecutar preparar_publicacion.py después de editar CSS, contenido, configuración o app y publicar los recursos y las entradas generadas.

Publicación e iframe se registrarán únicamente después de verificar la versión real. Esta carpeta no modifica el portal. El canvas conserva el trabajo localmente y permite exportar texto; no lo envía al docente ni acredita códigos o aprendizajes.
