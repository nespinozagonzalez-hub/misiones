# El Espejo Compartido

Presentación web portátil de la sesión 13 de *Buscadores de la Gamificación Perdida*.

- Cierre del módulo 4: 90 minutos sincrónicos, sin carga autónoma.
- Presentaciones relámpago de cinco minutos y retroalimentación cruzada.
- Pauta exacta del Anexo H reutilizada como apoyo, sin puntos ni pesos.
- Persistencia aislada: `ludaria_espejo_compartido_v1`.
- El facilitador organiza el orden y el intercambio real; el HTML no asigna personas ni envía registros.
- El Fragmento IV se revela solo cuando el facilitador conduce el cierre.

La guía completa está en `GUIA_DOCENTE.md`.
